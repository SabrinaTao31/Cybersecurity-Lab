# Learning guide

## 01 — Integrity
Create a fictional text file, calculate its SHA-256 digest, change its content and compare the result. Explain why the expected digest must come from a trusted source. A hash does not establish authorship by itself.

## 02 — Encoding
Encode and decode a fictional message with Base64. Explain why anyone can reverse this transformation without a secret key.

## 03 — Validation
Study the project identifier format AA-1234. Add tests for empty input, whitespace and invalid characters. Explain why input validation alone does not guarantee application security.

## Portfolio reflection
For each module, document your own observations, test results and limitations before marking it complete.
