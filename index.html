01 / INTEGRITY

File fingerprint

Chaque fichier possède une empreinte calculée à partir de son contenu. SHA-256 permet de comparer cette empreinte à une référence fiable pour détecter une modification. Une empreinte seule ne prouve pas l’origine du fichier.

04 / FIELD NOTES

Know your tools.

What is a fingerprint?

A SHA-256 digest represents file contents. Compare it with a trusted reference to detect changes.

Is Base64 encryption?

No. It is reversible without a secret key.

Why validate input?

Explicit rules reject unexpected formats, but are only one part of secure development.
